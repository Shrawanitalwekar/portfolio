# Shrawani Talwekar — Portfolio

A responsive, animated personal portfolio built with HTML, CSS and JavaScript.

## Included
- Animated hero and scroll reveal effects
- Skills, projects, certifications, achievements and volunteering
- RentEase live project link
- GitHub and LinkedIn links
- Downloadable resume
- Responsive navigation and mobile layout
- Reduced-motion accessibility support

## Run locally
Open `index.html` in a browser, or use any static server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `resume.pdf`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/root` folder.
6. Save and open the generated Pages URL.
